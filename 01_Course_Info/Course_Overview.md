# 课程概况

来源：https://moodle.hku.hk/course/view.php?id=139883  
保存日期：2026-11-08。以下为页面信息整理；Text and Reference 已省略。

课程介绍凸优化理论、算法和应用，并简要涉及非凸优化。主题包括凸集、凸函数、线性规划、二次规划、半定规划、几何规划、整数规划、向量优化、对偶、拉格朗日乘子、KKT 条件、梯度下降、牛顿法、内点法、椭球法、次梯度法和分解方法。

学习目标：掌握凸集、凸函数和凸规划的基本概念；掌握对偶理论和代表性求解算法；能够将实际问题建模为凸规划，并设计或应用算法、以学术论文形式呈现结果。
